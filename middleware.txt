The endpoint is /visits/get
 
The update procedure has been split into two lambdas, one for gaps and one for labs
 
The update lab endpoint is /labs. The payload should be in the format below:
 
{
    "PSC_Account__c": "001O300000SDK4DIAX",
    "Id": "a0UO300000DVZq4MAH",
    "PSC_Outcome__c": "Not Completed",
    "PSC_Not_Completed_Reason": "Incomplete Consent"
}
 
The PSC_Outcome__c can only be enum of 'Completed' or 'Not Completed'. The PSC_Not_Completed_Reason is also on enum of the following values:
Kit Left Behind
Incomplete Consent
Not Medically Indicated
Patient Refused
Safety Concerns
Technical Issues
Test Deferred
 
The response will be in the format below, mainly showing if there is an error message:
 
[
    {
        "Operation": "update",
        "Id": "a0UO300000DVZq4MAH",
        "ErrorMessage": null
    }
]
 
The update gap enpoint is /gaps. The payload should be in the format below:
 
{
    "Id": "a1rO300005ByO6kIAF",
    "PSC_Outcome__c": "Not Completed",
    "PSC_Not_Completed_Reason__c": "Incomplete Consent"
}
 
The response and PSC_Outcome__c and PSC_Not_Completed_Reason__c are the same as the labs
